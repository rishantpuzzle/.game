VITA BATTLE ROYAL INDIA — PROTOTYPE 1.0

FILES
- index.html : game UI and page structure
- style.css  : menu, HUD, responsive layout and mobile controls
- game.js    : Three.js scene, player movement, camera, bots, shooting and health logic

HOW TO RUN (BEGINNER)
1. Download and extract Vita-Battle-Royal-India.zip.
2. Install Visual Studio Code (if you don't have it).
3. In VS Code, open File > Open Folder and choose the extracted Vita-Battle-Royal-India folder.
4. Install the VS Code extension called "Live Server" by Ritwick Dey.
5. Right-click index.html and choose "Open with Live Server".
6. The game opens in Chrome. Internet is needed to load Three.js from jsDelivr.
7. Click START TRAINING.

CONTROLS — PC
- W/A/S/D or arrow keys: move
- Mouse: look around (click the game area to enable pointer lock)
- Left mouse button: shoot
- Shift: sprint
- Space: jump
- Esc or pause button: pause/resume

CONTROLS — MOBILE
- Left on-screen joystick: move
- Drag the right side of the screen: look around
- FIRE: shoot
- JUMP: jump

CURRENT PROTOTYPE FEATURES
- Procedurally built 3D training ground with houses, trees, rocks and river
- Third-person follow camera
- Six basic training bots with health bars
- Hit-scan shooting with simple tracer
- Player health, bot counter, victory/defeat and restart
- Responsive mobile controls

CURRENT LIMITATIONS
- This is a starter prototype, not a finished Free Fire-scale game.
- The training bots use simple movement and close-range damage, not advanced combat AI.
- There is no real online multiplayer, account system, inventory, safe-zone circle or persistent save yet.
- Three.js is loaded from a CDN, so the first run requires an internet connection.
- Performance depends on the user's device and browser.
